Prosty projekt typu issue tracker stworzony głównie w celach edukacyjnych.
Aplikacja symuluje narzędzie do zarządzania zgłoszeniami (bugi, zadania, problemy), ale jej głównym celem była nauka budowy aplikacji webowej z komunikacją frontend ↔ backend.

To nie jest produkcyjne narzędzie, tylko środowisko do ćwiczenia architektury i przepływu danych.
